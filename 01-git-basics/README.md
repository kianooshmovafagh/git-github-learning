# Git Basics

## Introduction

Git is a distributed version control system that helps developers track changes in source code and collaborate on software projects.

## What is Version Control?

Version control is a system that records changes to files over time. It allows developers to track modifications, compare versions, and restore previous states when necessary.

## Git Fundamentals

### 1. Repository
A repository is a directory tracked by Git. It contains project files and their version history.

### 2. Working Directory
The working directory contains the current project files where modifications are made.

### 3. Staging Area
The staging area allows developers to select which changes will be included in the next commit.

### 4. Commit
A commit is a snapshot of the staged changes recorded in the repository history.

### 5. Git Configuration
Git configuration stores user information and preferences, such as username and email.

## Basic Git Workflow

The typical Git workflow consists of:

1. Modify project files.
2. Stage changes.
3. Commit changes.
4. Review project history.
