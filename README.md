# Git & GitHub Learning

A hands-on learning repository documenting my progress in Git and GitHub. It includes structured notes, command references, and practical exercises completed through command-line practice.

The goal is to build a solid version-control workflow that supports collaborative software development and my path toward becoming a Python Backend Developer.

## Learning Objectives

- Understand version control and Git fundamentals.
- Track changes and manage the staging area and commit history.
- Create, switch, compare, and merge branches.
- Understand merge conflicts and how to resolve them.
- Work with local and remote repositories.
- Use GitHub collaboration workflows.
- Practice safe techniques for inspecting, restoring, and undoing changes.
- Develop clear commit messages and maintain useful project documentation.

## Workflow

The repository is maintained using a practical Git workflow:

1. Create a dedicated feature branch for a topic or set of changes.
2. Add and update documentation and exercises.
3. Review changes before committing.
4. Commit changes with descriptive messages.
5. Push completed work to GitHub.
6. Merge the work into the `main` branch.
7. Keep the repository clean and synchronized.
