# Git & GitHub Learning

A practical repository documenting my journey of learning Git and GitHub through hands-on exercises, command-line practice, and real-world workflows.

## Learning Goals

- Understand Git fundamentals and version control.
- Manage files and track project changes.
- Work with branches and merge strategies.
- Understand local and remote repositories.
- Collaborate through GitHub workflows.
- Practice resolving merge conflicts.
